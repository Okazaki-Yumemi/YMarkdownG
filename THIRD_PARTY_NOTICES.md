# Third-party notices

YMarkdownG adapts the color palettes of these community themes. These are application-specific palette adaptations, not official ports or complete reproductions of the VS Code themes. Some secondary text colors are adjusted for legibility.

- **One Dark Pro** — Binaryify. [Source](https://github.com/Binaryify/OneDark-Pro), [MIT license](docs/licenses/one-dark-pro.txt).
- **GitHub Light / Dark** — GitHub Primer. [Source](https://github.com/primer/primitives), [MIT license](docs/licenses/github-primer.txt).
- **Dracula** — Zeno Rocha and contributors. [Source](https://github.com/dracula/dracula-theme), [MIT license](docs/licenses/dracula.txt).
- **Nord** — Arctic Ice Studio and contributors. [Source](https://github.com/nordtheme/nord), [MIT license](docs/licenses/nord.txt).

Rich editing uses Tiptap / ProseMirror; Markdown parsing uses marked; math typesetting uses KaTeX; code highlighting uses CodeMirror, highlight.js and lowlight. Their licenses are distributed with their dependencies. KaTeX fonts are bundled locally and embedded in exported PDFs.
